# Krea.ai 交互与样式设计体系分析及对标指引

## 一、概述与核心设计哲学

Krea.ai（特别是在其 `/edit` 图像编辑、`/image` 生图、`/realtime` 实时画板与 `/nodes` 节点编辑器中）代表了当前 **AI Native 创作平台** 的顶尖设计范式。

其核心哲学可以概括为：
1. **隐藏模型心智与底层代码**：绝不让最终用户感知到复杂的数据结构（JSON、提示词注入模板、坐标归一化等），用户只与视觉对象、自然语言、手势手柄交互。
2. **沉浸式暗黑工业美学（Dark Minimalist Studio）**：通过极其纯净的无彩色黑灰阶层构建舞台背景，让用户的内容（图像与主体）成为第一视觉重心。
3. **超精细物理像素控制（Subpixel Scale Invariance）**：在无级缩放的画板中，所有辅助控制线、手柄、标签始终保持屏幕物理视网膜级别的锐利度，不因画布放大而粗化，也不因缩小而糊成一团。
4. **即时连续反馈（Direct Manipulation）**：手势所见即所得，选中即聚焦，属性与动作就近附着于对象本身，而非远距离的复杂表单。

## 二、色彩系统（Color System）

Krea 的色彩体系构建在现代 **OKLCH / OKLAB** 颜色空间之上，呈现出高对比、低眩光、纯黑灰阶特征。

### 1. 基础阶层与表面色（Surfaces & Backgrounds）

| 层级名称 | 对应 Hex / 变量 | 色彩值（OKLCH / RGB） | 用途说明 |
| :--- | :--- | :--- | :--- |
| **Canvas Void (画板底)** | `#101010` | `rgb(16, 16, 16)` | 无限画板、视口最深底色，提供极低光干扰的创作舞台 |
| **App Surface (侧边栏/容器)** | `#141414` | `oklch(0.14 0 0)` | 左侧导航栏、抽屉背景，略微高于画布底色 |
| **Panel Surface (浮动面板)** | `#1a1a1a` | `oklch(0.18 0 0)` | 右侧编辑抽屉、属性卡片、浮动工具栏底色 |
| **Card / Hover Overlay** | `#242424` | `oklch(0.24 0 0)` | 悬停态、次级卡片容器、选项行激活态 |
| **Active / Control Track** | `#2e2e2e` | `oklch(0.29 0 0)` | 输入框背景、滑块轨道底色、折叠区标题底色 |

### 2. 边框与微弱分割线（Borders & Dividers）

Krea 几乎不使用实体实色线条，而是完全依赖 **Alpha 半透明白叠加**：
- **Subtle Border**：`oklch(1 0 0 / 0.08)` 或 `rgba(255, 255, 255, 0.08)`（面板分割线、次级按钮边框）
- **Normal Border**：`oklch(1 0 0 / 0.14)`（输入框、卡片边框）
- **Focused / Hover Border**：`oklch(1 0 0 / 0.35)`（获得焦点或鼠标悬停时的边缘提亮）

### 3. 文字色阶（Typography Colors）

- **Primary Text**：`oklch(0.985 0 0)`（近乎纯白 `#fafafa`，用于主要标题、按钮文字）
- **Secondary Text**：`oklch(0.70 0 0)`（`#b3b3b3`，用于属性名、输入框 label、描述）
- **Muted / Placeholder**：`oklch(0.45 0 0)`（`#737373`，输入提示、不可用状态、快捷键提示）

### 4. 品牌与交互强调色（Brand & Accent）

Krea 没有采用单一饱和度的霓虹色，而是配合场景提供专用功能色：
- **Primary Action (生成/确认)**：
  - 常态背景：`oklch(0.98 0 0)`（黑白反转纯白高亮）配合暗色字体，或品牌电光蓝 `oklch(0.58 0.25 257.0)`（`#2563eb` ~ `#3b82f6` 区间）。
  - 半透明辅色：`oklab(0.58 -0.06 -0.24 / 0.15)`（用于次级选区、选中徽章背景）。
- **Bounding Box 选区与边框**：
  - 高亮选中态：极细高饱和强调色（如亮紫粉 `#a855f7` 或电光青 `#06b6d4`）。
  - 未选中/虚线态：`rgba(255, 255, 255, 0.35)`。
- **Status Colors**：
  - 成功 / 质量良好：翠绿 `oklch(0.65 0.20 145)`（`#10b981`）
  - 警告 / 需要重构：琥珀黄 `oklch(0.75 0.18 75)`（`#f59e0b`）
  - 危险 / 失败：绯红 `oklch(0.60 0.24 25)`（`#ef4444`）

## 三、几何、形状与排版规范（Shapes & Geometry）

### 1. 圆角哲学（Border Radius）

Krea 在容器与交互控件上采用了严格的**层次化圆角连续性（Concentric Radii）**，但对于几何画板对象保持绝对的**数学锐利度**：

- **大面板 / 模态卡片（Outer Container）**：`16px` ~ `20px`（现代大圆角，沉浸柔和）
- **按钮 / 输入框（Interactive Controls）**：`10px` ~ `14px`（例如 Primary 按钮为 `14px`）
- **小图标按钮 / Tag 徽章（Pills & Tags）**：`6px` ~ `8px`，或者完全纯圆形 `border-radius: 9999px`（如折叠圆钮、圆形画笔色板）
- **几何边界框（Bounding Box）**：**`0px` 绝对直角**
  - 画布中的裁剪框、bbox 边框一律使用直角（`border-radius: 0`），以确保四角缩放手柄的几何顶点精准重叠，避免在高倍放大时边缘圆角向内凹陷导致控制手柄悬空。
- **缩放手柄（Transform / Resize Handles）**：**`0px` 绝对直角小方块**
  - 控制点尺寸恒定在屏幕物理大小（如 `10px × 10px`），纯实心白或品牌色带细微暗色描边。

### 2. 字体与排版（Typography）

- **主字体家族**：`"Suisse Intl", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
  - 具有极强的现代瑞士国际主义设计风格，字形紧凑工整。
- **字阶设计**：
  - `11px`：数据指标、tag 条序号、微型快捷键提示（`font-weight: 500`, `tabular-nums`）
  - `13px / 14px`：常规控制项、属性名、输入框正文、按钮文字（`font-weight: 450 ~ 500`）
  - `16px`：小章节标题、二级分组名（`font-weight: 600`）
  - `20px+`：主页面或模态窗大标题（`font-weight: 700`）

## 四、对象编辑与画布交互逻辑（Direct Manipulation & BBox）

Krea 在编辑模式（`/edit`）下的交互手感之所以流畅，核心在于遵循了以下四大交互原则：

### 1. 屏幕视网膜级恒定视觉（Scale Invariant Elements）

在基于 WebGL / SVG / CSS Transform 的画布缩放体系下，普通像素会随着画板放大而无限放大（导致 1px 细线变成 20px 巨型色块）：
- **反比缩放（Counter-Scaling）**：
  - Krea 对所有辅助元素（BBox 边框线条粗细、4角手柄尺寸、文字标签、气泡按钮）使用反比例公式抵消：
    $$\text{Actual Pixel} = \frac{\text{Target Screen Pixel}}{\text{Canvas Zoom}}$$
  - **效果**：无论用户放大到 50% 还是 400%，在用户的显示器视网膜上看，边框线条永远是纤细锐利的 1.5~2 物理像素，手柄永远是精确好点的 10~11 物理像素小方块。

### 2. 四角手柄与锚点映射（Quadrant-Aware Resizing）

- 选中对象时只激活**四角方块手柄（NW, NE, SW, SE）**与旋转手柄（顶部正中延展杆）。
- 拖拽 NW（左上角）手柄时，对角 SE（右下角）固定为不动锚点，动态更新左上角 $(x, y)$ 与 $(w, h)$。
- 拖拽过程按住 `Shift` 自动约束宽高比等比缩放。
- 支持最小安全尺寸保护（例如不小于 `10px × 10px`），防止反向拖拽造成宽高倒置塌陷。

### 3. 就近动作与无模态交互（In-Context Actions）

- 传统图形软件要求用户在右侧属性栏里翻找属性。
- Krea 将最核心的动作直接贴合在被选对象旁边（即本编辑器实现的 BBox Tag 顶部胶囊条）：
  - 显示当前区域序号、模式（对象 / 文本）
  - 内嵌 AI 优化快捷触发器（✨ 按钮）
  - 当边界框靠近画布顶部边界时，胶囊条自动智能翻转至框内上缘（`inside` 模式），永不溢出被裁剪。

### 4. 区域化聚焦（Region-Focused AI Prompting）

在 Krea 中：
- 用户不选中任何区域时，提示词代表「全图构图 / 全景变更」。
- 一旦用户用矩形或选区工具选中特定区域，界面立即进入「针对该选区提问（Change Region / Annotate）」模式：
  - 输入框自动显式绑定当前选区（“在选区中画什么…”）。
  - 用户可随时解除，切换回全局提问。
  - 生成结果仅局部替换该 BBox，画布其余要素与全局环境无损保留。

## 五、在本项目（ideogram4-editor）中的落地对照表

| 设计要素 | Krea 原始设计标准 | 本项目已落实的对标改造 |
| :--- | :--- | :--- |
| **画布信息呈现** | 彻底不展示代码，只展示画面与图层 | 隐藏 ```json 语法块，转换为一行场景人话摘要 + 画布快照缩略图 |
| **BBox 直角与手柄** | 纯直角、4角小方块手柄紧贴顶点 | `border-radius: 0`，选中展示 NW/NE/SW/SE 4 角直角小方块手柄，Shift 等比约束 |
| **缩放线宽与手柄比例** | 屏幕物理像素恒定（反比 zoom 抵消） | 边框锁定屏幕 2px 视觉宽度（`calc(2px / var(--box-zoom))`），手柄 11px 方块永远大于边框 |
| **AI 按钮交互** | 极简、不畸变、就近贴附 | 标签条内嵌无粗外框 AI 按钮，`aspect-ratio: 1/1`，高倍缩放绝不椭圆扭曲 |
| **选区提问** | 选区上下文绑定输入框 | 新增 `CanvasChatRegionBar` 自动绑定当前选中 BBox，可点 × 解除 |
| **局部 Apply** | 仅变更选区内容，整图撤销 | 新增 `applyRegionExtractionToStore` 仅替换目标 box，且单次操作只压一次撤销栈 |
| **专业与极简模式** | 默认纯净工具流，保留排查入口 | 新增「显示开发者工具」开关，默认纯净零代码，开启时展示 Terminal 与技术数值 |
| **布局检测反馈** | 自然语言直述问题 | `LayoutQualityDialog` 翻译为「元素偏小」、「贴近边缘」等人话清单 |
